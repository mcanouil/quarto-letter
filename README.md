# Letter Format Template

This is a Quarto template that assists you in creating a letter.

## Creating a New Letter

```bash
quarto use template mcanouil/quarto-letter@1.2.1
```

This will install the extension and create an example qmd file you can use as a starting place.

## Installation For Existing Document

```bash
quarto add mcanouil/quarto-letter@1.2.1
```

This will install the extension under the `_extensions` subdirectory.
If you're using version control, you will want to check in this directory.

## Documentation

The full documentation lives at <https://m.canouil.dev/quarto-letter/>: every option, the diagnostics, the editor snippets, and worked front matter for an English letter, a French one, and one with a letterhead and signature.

[`template.qmd`](template.qmd) is a complete starting point you can copy, and a rendered letter is attached to each release.
